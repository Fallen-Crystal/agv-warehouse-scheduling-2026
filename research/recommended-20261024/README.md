数据先执行 `python data/unpack.py` 还原并验原始字节；主运行已经自带选中窗口，不需联网或读取40MB全库。[数据说明](data/README.md)明确真实请求与模型假设的区别。入库和出库自然部分重叠，一单一单位运输，批次之间安全待命，全部流关闭且任务完成后最终返库。

独立线性目标：$F=0.5T/900+0.3R/900+0.2D/5400$。T=最后订单完成时刻，R=平均发布到完成耗时，D=包含最终返库的实际总里程；辅助保留空驶/P90/等待/CPU。权重是当前实验设定，不是文献证明的唯一最优值。F可超过1，没有统一0.8达标线。
