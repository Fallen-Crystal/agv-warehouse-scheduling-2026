# 目标函数与权重文献核对（2026-10-22）

**核心结论**：将平均订单响应耗时 `R` 与车队总行驶里程 `D` 同时纳入多目标评价具有清晰业务意义——前者刻画订单服务水平，后者刻画车辆运行成本。本阶段保留 `T`、`R`、`D` 三项指标并以 `0.5 / 0.3 / 0.2` 作为课程项目设定的综合偏好权重，所有算法对照在同一固定目标下公平比较。

## 2. `R` 与 `D` 的业务区分

记订单 $i$ 的释放时刻为 $r_i$、卸货完成时刻为 $C_i$：

$$R = \frac{1}{n}\sum_{i=1}^{n}(C_i - r_i), \qquad D = \sum_{\text{all AGVs}} \text{实际移动格数}.$$

`R` 涵盖派单等待、空车接近、装货、载货运输、交通等待与卸货全过程；`D` 仅统计空间位移步数，不含原地等待与装卸。在多车并行动态系统中，多辆车的移动同时发生，总里程与平均响应时间具有不同的优化维度：

- 多目标指标允许存在相关性但分别刻画不同业务后果：一次移动既消耗车辆运行资源又影响订单交付耗时。仅在单车、全静态、固定服务时间的退化情形下两者高度线性一致；在多车动态场景中往往存在真实权衡。
- 例如：某已释放订单附近有一辆车 8 步后空闲、再走 2 步可到货架，而另一辆远处空闲车立即可出发走 6 步到达；等待近车可节省 4 格行驶里程，但取货开始推迟 4 步，调度器需结合全局队列与交通状态综合权衡。
- 本项目定义能耗展示项 `E = 0.05*D`，由于 `E/Eref = D/Dref`，`E` 仅作辅助展示而不再重复加权。空驶里程可拆解为辅助诊断指标单独观察。

## 3. 同时保留 `T` 与 `R` 的原因

`T = max_i C_i` 关注整批任务的最晚完工时刻，`R` 关注全部订单的平均响应体验，两者刻画不同统计特性。例如零时刻释放的两笔订单，完成时刻分别为 `(4, 10)` 与 `(8, 10)` 时 `T` 相同而 `R` 差异显著。同时保留 `T` 与 `R` 既能防止为压缩多数短单而拖慢尾单，也能防止尾单不变时忽略整体平均响应的改进。

权重组合 `0.5*T/Tref + 0.3*R/Rref + 0.2*D/Dref` 整体偏重时间效率并兼顾行驶成本，其显式边际交换关系为：

- 在 `T` 不变时，`R` 降低参考值的 1% 等价于 `D` 增加参考值的 1.5%；
- `T` 降低参考值的 1% 等价于 `R` 增加参考值的约 1.667%，或 `D` 增加参考值的 2.5%。

上述边际权衡清晰表达了目标函数的业务偏好；正权重加权和下的精确最优解具有帕累托非支配性质，而有限预算启发式搜索在可行解空间内力求综合成本最优。

## 4. 权重设计与约束原则

1. 本阶段固定采用 `0.5 / 0.3 / 0.2` 作为明确声明的课程项目综合偏好权重。
2. 通过预先设计的权重敏感性分析检验算法排名对权重变化的稳健性。
3. 权重设定与尺度定义配合使用；当缺乏专家打分或真实电价数据时，优先保持透明公开的偏好设定并开展多组权重对比。
4. 若面向不同业务场景调整为 `R/D` 双目标或其他版本，应在统一修改搜索、验解、精确参照与报告口径后独立开展实验。
5. 全部订单完成、多车无碰撞、合法货架取放与最终返库均为硬约束，所有有效方案必须严格满足。

## 5. 归一化口径与动态订单特点

同一场景采用固定基准 `(Tref, Rref, Dref)` 供所有算法共用：`F = 1` 表示综合表现与参考基准相当，`F < 1` 表示相对参考基准取得综合改善。`T` 计至最后一单交付完成（不含最终返库时间），`D` 包含最终返库里程。

在线策略仅可见已释放订单，离线完整场景基准仅用于最终统一评分；在线搜索内部基于当前可见任务构造预测代理评分以指导滚动决策。

## 6. 已有 72 场景轨迹的离线权重敏感性核对

基于上一轮 72 个成对场景的合法轨迹，在不重新运行优化器的前提下按多组权重重新计分，以检验既有轨迹排名的稳健性：

| `T / R / D` 权重 | v1 GA 相对贪心的平均综合改进 | 改进 / 退化场景 |
|---|---:|---:|
| 0.5 / 0.3 / 0.2 | 7.750% | 72 / 0 |
| 1/3、1/3、1/3 | 6.419% | 70 / 2 |
| 0.6 / 0.2 / 0.2 | 9.152% | 72 / 0 |
| 0.3 / 0.5 / 0.2 | 4.945% | 66 / 6 |
| 0.3 / 0.3 / 0.4 | 6.454% | 70 / 2 |

结果表明，在五种不同权重偏好下，v1 GA 相对贪心均保持明显正向平均改善（4.945%–9.152%），同时个别场景的优劣排序随权重偏好发生合理变化；72 个场景中有 31 个场景 GA 在三项指标上同时支配贪心，其余场景体现了指标间的综合权衡。

例如在 `large-multi_dynamic-3000` 场景中，贪心策略为 `R = 135.75` 步、`D = 922` 格，v1 GA 为 `R = 142.50` 步、`D = 904` 格，综合指标 F 从约 `0.99957` 降至 `0.96875`，直观展示了 `R` 与 `D` 在多车动态调度中的实际权衡现象。
