# 目标函数与权重核对（2026-10-22）

结论：平均订单耗时R与总里程D同时纳入目标是合理的；它们分别衡量订单服务水平与车辆移动成本。当前T、R、D可以保留，0.5/0.3/0.2是项目采用的偏好设定，不能说是论文证明的通用最优权重。本轮算法比较继续固定原F；没有为了让结果更好看而换权重。

## 2. R和D是否重复

记订单i释放时刻为r_i，卸货完成时刻为C_i：

R = (1/n) Σ(C_i-r_i)，D = Σ所有车辆实际移动格数。

R包含派单等待、前往取货、装货、载货运输、交通等待、卸货。D不包含原地等待或装卸。多车同时运行时，几辆车的移动可并行发生，里程相加不等于订单完成时间相加。

多目标指标不要求统计独立。一次移动既消耗车辆资源又影响订单耗时，可以具有两种业务后果；与E严格等于0.05D的代数冗余不同。只有在某些退化情形，例如单车、全静态、固定服务时间且不考虑返程差异时，时间和路程会紧密关联，不能把这种特例推广到多车动态系统。

例如某个已释放订单，附近车辆8步后空闲，再走2步到货架；远处空闲车辆现在走6步即可到达。若后续取货和送货相同，等近车可少走4步，但取货开始晚4步。该局部例子说明可能存在取舍，实际整批效果仍需连同其他订单和冲突评价，不能仅凭这个例子选车。

E=0.05D是当前明确约定，因此E/Eref=D/Dref，不能把E和D当两个独立目标重复加权。空驶里程可以拆解观察；如要额外惩罚空驶，应明确改变经营偏好。空驶率不是天然更好的主目标，增加无意义载货路程也可能降低该比率。

## 3. T与R保留的理由

T=max_i C_i，关注最后一单；R关注全部订单平均体验。二者并非同一个统计量。例如零释放的完成时刻(4,10)与(8,10)，T一样、R不同。保留T可避免只改善多数短单而牺牲最后几单；保留R可避免最后一单不变时忽略多数订单的改善。

当前0.5T/Tref+0.3R/Rref+0.2D/Dref总体偏重时间相关表现。这是综合折中，不代表三项分别都达到自己的最小值，也不能保证唯一最优解。正权重下，若真正求到加权F的全局最优，该解不会被另一可行方案在三项上同时支配；有限预算GA本身不提供这一保证。

当前权重的具体含义是：T不变时，R减少参考值的1%，恰好抵消D增加参考值的1.5%。注意这里都是各自参考值的百分比，不是候选方案当前值的百分比，也不是说1秒能固定兑换1.5格。T减少参考值的1%，则可抵消R增加参考值的约1.667%，或D增加参考值的2.5%。这些交换关系比“哪个权重数字大”更能说明实际偏好，但不表示仓库一定存在对应可行方案。

## 4. 对权重的建议

1. 当前阶段保留已冻结的0.5/0.3/0.2，作为课程项目明确声明的综合偏好，而不是声称有通用科学最优比例。
2. 做少量预先确定的权重敏感性分析，回答结论是否依赖某一个比例；不必把“找到对本算法最有利的权重”当优化任务。
3. 等权重也需要尺度约定；“不清楚偏好就等权”是一种透明约定，不是比其他比例更客观的定理。没有专家判断资料时，不虚构AHP打分；指标波动大也不自动意味着业务价值高。
4. 若最终研究重点明确为订单服务水平与运输成本，可把R、D作为双目标，T作为另行报告的整批指标；这是另一版业务目标，须统一修改搜索、验解、最优参照和报告后重新实验。暂不自动采用。
5. 完成全部订单、无碰撞、合法取货、最终返库属于硬约束，不能以较低成本换取违反。没有规定交付期限/紧急等级时，不凭空增加“迟到罚金”或“紧急度”权重。

## 5. 归一化与动态订单的注意点

同一场景固定Tref/Rref/Dref，所有算法共用，分母不可取各算法自己的结果或随候选方案变化。F=1表示与固定参考组合相当；F<1表示综合改进，并不是最优性证书，也没有跨项目通用的优秀阈值。

当前T从仿真时刻0计到末次交付，不含最终返库时间；D包含最终返库里程。这两种口径都要在论文中明示。动态流中的释放间隔可能稀释T的相对改进；可辅助报告Cmax-max(r_i)和最终回库时刻，但不能混用公式或更换分母后继续沿用旧成绩。

在线政策只见已释放订单。完整场景归一化在离线评价器中使用，不能泄漏给在线算法。政策中基于当前可见工作量的预测评分是决策代理，虽然也用0.5/0.3/0.2，却不是最终离线F的全局最优证明。

## 6. 已有结果的离线敏感性核对

使用上一轮72个成对场景的原始合法轨迹重新计分，没有重新运行新权重优化器：

| T/R/D权重 | v1 GA相对贪心的平均综合改进 | 改进/退化场景 |
|---|---:|---:|
| 0.5/0.3/0.2 | 7.750% | 72/0 |
| 1/3、1/3、1/3 | 6.419% | 70/2 |
| 0.6/0.2/0.2 | 9.152% | 72/0 |
| 0.3/0.5/0.2 | 4.945% | 66/6 |
| 0.3/0.3/0.4 | 6.454% | 70/2 |

解释：已有改进在这些设定下平均仍为正，但各场景结论会改变；增大T权重让旧算法的成绩更好，不能反过来据此证明更大T权重合理。72个场景中仅31个是GA在三项上帕累托支配贪心，其他改进多含取舍。

这些是固定轨迹的后处理，只描述这组候选解的排序稳定性。不能据此声称已经求到各权重下的最优策略或完整帕累托前沿。新一轮保持原F的算法实验另行报告。

一个实际取舍例子：上一轮large-multi_dynamic-3000场景中，贪心R=135.75步、D=922格；v1 GA为R=142.50步、D=904格。里程减少但平均耗时增加，原F从约0.99957降至0.96875。此例只用于展示R与D可分开变化，不代表所有场景的平均表现，也不是两个指标因果独立的证明。
