# 仓库 AGV：独立线性适应度版本

本阶段将“优化目标定义”与“算法间对照比较”彻底解耦，采用基于公开物理参数的独立线性目标函数：

- 等效时间成本：`J = 0.5*T + 0.3*R + 0.2*D/(6×1)`（单位：等效秒）
- 无量纲主目标：`F_linear_v2 = J/900 = 0.5*T/900 + 0.3*R/900 + 0.2*D/5400`

其中 `T`、`R` 以秒计，`D` 以网格步数计；分母完全由实验窗口时长、车辆数与车速等公开物理参数确定，独立于 FCFS、ETA 或其他基准算法。权重保留 `0.5 / 0.3 / 0.2` 作为课程项目综合偏好。

建议先阅读 [线性适应度与实验评价方案.md](线性适应度与实验评价方案.md)，再阅读 [迁移复核报告.md](迁移复核报告.md) 了解迁移后的实际复核数据。由于去除了相对基准分母，新版 `F` 需在统一新口径下独立分析。

## 文件结构

- `objective.py`：统一评分定义，先执行独立验解再计算最终目标值；
- `v2/`：已切换至独立线性目标的简化 GA、代理排序、完整试排与下界剪枝；
- `data/protocol.json`：冻结的权重、尺度、场景、搜索预算与复核范围；
- `engine/`：逐字节保留的物理内核、独立验解器、地图与路径依赖（哈希见 `data/engine-manifest.json`）；
- `run_linear.py`：独立运行入口，可直接为单个算法输出正式 `F`；
- `results/linear/`：原始执行轨迹与完整日志；
- `tests/`：目标一致性、物理合法性、信息隔离与可复现性单元测试。

## 运行方式

仅需 Python 3.12 标准库（输出文件须为新路径）：

```text
python run_linear.py --case wepa-day45-bin4335 --method soft_ga --router sipp --seed 0 --output my-run.json
python -m unittest discover -s tests -v
```

`--method` 支持 `soft_ga`、`simple_ga`、`eta`、`fcfs`；`--router` 支持 `sipp`、`astar`、`aco`（其中 `aco` 为 ACO 引导空间 A\* 通道结合 SIPP 安全时间窗解码的混合路径后端）。`study.py --run` 用于执行 12 次开发复核实验。本阶段基于公开真实订单流驱动的课程仿真模型开展目标接口迁移复核。
