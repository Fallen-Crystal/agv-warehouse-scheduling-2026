# AGV 动态预测边界对照版

本版基于 2026-10-24 诊断版已选定的 `gate`，增加 `open_gate`，只改变内部已知任务预测的终止方式。两者均使用低负载即时匹配、联合遗传搜索和 SIPP。其他旧候选保留用于回归检查，不属于本轮选型。

`gate`：每次预测均把已知订单当作最后一批并预测全车返库。

`open_gate`：脱敏观察保留真实公开的“是否关闭”标志。未关闭时，预测已知任务完成后车辆按原执行器安全待命；真正关闭后仍预测最终返库。代理排序与剪枝同步适配。算法看不到未来订单及真实关闭时刻。

实际车辆行为、库存规则、装卸层序、地图、待命规则、最终返库与独立评价不变。处理组只改预测，并未新增车辆重新定位策略或改变底层路径算法。

最终完整场景目标为 `F = 0.5*T/900 + 0.3*R/900 + 0.2*D/5400`，对应大型地图、6 车、速度每秒 1 格、900 秒请求窗口。T 不含最终返库耗时；D 包含全部实际移动及最终返库。开放流内部的部分需求预测分数不能当作最终 F。

在本目录运行（Python 3.10+，标准库即可）：

```powershell
python -m unittest test_boundary test_variants -v
python run_main.py --case wepa-day47-bin4568 --seed 0 --output trial.json
python run_main.py --case wepa-day47-bin4568 --profile open_gate --output candidate.json
```

`run_main.py` 默认采用结果报告中的推荐策略；也可以明确选择两种对照之一。输出文件不得预先存在。完整路径、任务记录、F 分项、计算耗时、独立验解和源码哈希都保存在输出中。若修改实验算法或协议，冻结入口会拒绝继续宣称复现实验，应建立新的版本。

文件说明：`improved/forecast.py` 为预测终止与剪枝，`improved/proxy.py` 为代理终点成本，`improved/policy.py` 为一致的观察传递；`baseline/` 是冻结的上一版依赖。`docs/实验设计.md` 记录预定条件，`docs/结果报告.md` 记录实际结果，`results/comparison.csv` 和各阶段 `traces/` 保留全部原始运行。

真实请求来源仍为公开 WEPAStacks/slapstack 固定提交的数据；模型中的货位、网格、单位速度和装卸规则属于本项目的映射仿真。起始库存来自源请求前缀台账，不是现场在制品测量。没有用源厂真实完成时间或实际轨迹做虚构对照。

此前看过的窗口均不再称为未见数据。本轮验证按输入条件固定四个此前未使用来源日、每场景两个随机种子；种子重复不等于额外独立场景。结果不构成完整动态多车问题的全局最优证明。
