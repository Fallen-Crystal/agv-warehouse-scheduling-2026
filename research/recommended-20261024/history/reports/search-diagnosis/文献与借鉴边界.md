# 文献与本轮改动的关系

1. Ropke, S.; Pisinger, D. (2006). *An Adaptive Large Neighborhood Search Heuristic for the Pickup and Delivery Problem with Time Windows*. Transportation Science. DOI [10.1287/trsc.1050.0135](https://pubsonline.informs.org/doi/10.1287/trsc.1050.0135)。作者研究带时间窗的取送问题，通过大邻域方法改善方案。本轮将恢复邻域搜索作为对照，但并未实现完整ALNS或自适应破坏重建，因此不能把本轮restored称作该论文算法的复现。

2. Vidal, T. *Hybrid Genetic Search for the CVRP: Open-Source Implementation and SWAP* Neighborhood*. [作者预印本](https://arxiv.org/abs/2012.10384)、[作者开源仓库](https://github.com/vidalt/HGS-CVRP)。研究将遗传搜索和专门邻域改善结合，说明“遗传算法”内部的种群、邻域与评价实现同样重要。其CVRP假设不同于本项目动态库存和多车预约系统；本轮没有移植HGS、SWAP*或其C++源码，也没有继承其性能结论。

本轮guided只是有针对性的可行初始解扰动；不是完整混合遗传搜索，也不附带近似比。恢复旧多段框架、多初始解或增加搜索预算，都必须由本项目同规则实验验证，不能因文献采用某个名称就认定有效。

原SIPP仍负责真实无碰撞路径，未以欧氏距离或无避碰路线代替执行。当前批次匹配的“精确”只指固定估计边代价的指派子问题，不是整段动态订单和路径协调的全局最优。
