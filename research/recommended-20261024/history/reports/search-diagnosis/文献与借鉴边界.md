# 文献与本轮改动对照说明

1. **Ropke, S.; Pisinger, D. (2006).** *An Adaptive Large Neighborhood Search Heuristic for the Pickup and Delivery Problem with Time Windows*. *Transportation Science*, DOI [10.1287/trsc.1050.0135](https://pubsonline.informs.org/doi/10.1287/trsc.1050.0135)。该文提出了面向带时间窗取送问题的自适应大邻域搜索（ALNS）框架。本轮 `restored` 变体借鉴邻域修复思路作为历史框架对照，采用固定邻域操作而非完整自适应破坏重建机制。
2. **Vidal, T. (2022).** *Hybrid Genetic Search for the CVRP: Open-Source Implementation and SWAP\* Neighborhood*. [作者预印本](https://arxiv.org/abs/2012.10384)、[作者开源仓库](https://github.com/vidalt/HGS-CVRP)。该研究说明在遗传算法中，初始种群质量、邻域扰动与评价实现同样关键。本轮 `guided` 变体受此启发，面向本项目动态库存与多车预约环境设计了基于可行锚点的轻量局部扰动初始化策略。

所有对照变体均在同一固定物理规则、统一线性目标与真实 SIPP 无碰撞路径规划下通过配对实验评估；其中低负载批量匹配对当前固定估计边代价的指派子问题精确求解，多车动态调度整体属于在线启发式优化。
