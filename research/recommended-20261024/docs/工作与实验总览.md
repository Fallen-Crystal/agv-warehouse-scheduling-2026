# 阶段工作、方案比较与采用决定

## 工作脉络

先完善四邻接/混合货架、层序、柱和设备、批次待命与最终返库，修复独立验解与尾部计时等边界；随后研究订单匹配、GA/ACO/PSO与SIPP/A*等路径组合；再接入公开真实请求并扩展入库/出库部分重叠；最后统一独立线性F、诊断简化损失、建立小规模最优参照，并比较邻域、路径协调、复合换车重排和匈牙利初始化。原main的docs/results保留早期工程审核和合成实验；本目录归档近期研究。

改善率均按各轮自己的相同输入成对比较计算：先场景内平均随机种子，再平均逐场景相对下降率。不是跨轮平均F直接相除。不同轮窗口不同，因此不能把0.881377与0.896406比较后宣布另一方案全局胜出，也不能将所有重复运行相加冒称独立场景数。

最新实验36次=12开发+24验证，验证只有4个日期窗口、每方案2个种子；四个日期在早期研究用过。推荐gate的最新验证T=1130.625秒、R=292.843秒、D=4608格，F=0.896406；累计CPU约70.42秒/窗口，不是每次决策延迟，也不计入仿真F。原始逐次数据、种子和负例在完整包。

小规模最优参照：两车六个缩减问题中5个OPTIMAL、1个仅FEASIBLE；不得把后者当最优。后续匈牙利轮复核其中4个既有证书，gate/HGA均达到4例最优、滚动匈牙利达到2例。这只证明所列微例，不证明六车未知动态流接近最优或有近似比。

## 实验诚信与限制

- 所有轮次各有固定协议、源码指纹、原始轨迹和失败/退化记录。当前包复核52条轨迹、30项测试的历史证据保留；本次发布另有新的复核日志，不用历史通过数冒充本次全量新实验。
- Coupled轮有两条墙钟超预算记录（约2955/2978秒，CPU约180/188秒），未将异常从原结果中删除；一例重跑物理结果精确一致。原因未最终定位，主机暂停只是可能解释。
- 未在验证结果上重新调参/按最佳种子挑选。逐轮使用同一4个开发窗口，已有较多方法探索，不能把很小的验证收益说成确定优势。
- 当前权重为建模选择，未完成大规模权重敏感性分析；仅一个主地图/车队/层数，泛化覆盖有限。下一步建议另留真正未使用业务日，做车数4/6/8及层数3/5/8的小型敏感性实验，单独验证门控/软分区/预算作用。
- 已证明某些瞬时匹配与微型离线问题最优；整体是经实验比较的可行启发式方案，名称“推荐方案”不等于数学全局最优。
