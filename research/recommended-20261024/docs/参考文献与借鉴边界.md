# 参考文献与实现对应（2026-10-24 核对）

下表列出本项目在问题建模、调度算法、路径规划、公开数据及精确参照方面所参考的主要文献与官方资料，并说明各文献思想在本项目中的具体落地点与实现范围。本文仅链接公开论文与作者资料页面；历史归档报告中的引用以本文核对结果为准。

|---|---|---|
| Phillips, M.; Likhachev, M. (2011). *SIPP: Safe Interval Path Planning for Dynamic Environments*. ICRA, 5628–5635. [作者论文](https://www.cs.cmu.edu/~maxim/files/sipp_icra11.pdf), DOI 10.1109/ICRA.2011.5980306 | 安全时间区间压缩、启发式路径搜索 | 适配离散单位步长、预约表及连续装卸占位，在固定他车预约下规划单车无碰撞路径 |
| Ma, H.; Li, J.; Kumar, T. K. S.; Koenig, S. (2017). *Lifelong Multi-Agent Path Finding for Online Pickup and Delivery Tasks*. AAMAS. [作者论文](https://jiaoyangli.me/files/2017-AAMAS.pdf) | 在线持续到达的取送任务建模、任务指派与无碰撞路径分层 | 借鉴在线滚动派单与路径解耦架构，结合本项目仓储层序与库存规则独立实现 |

**引用勘误**：历史 `coupled` 实验设计文档曾将 Ropke & Pisinger (2006) 的 DOI 误记为 `10.1287/trsc.1100.0135`，正确 DOI 为 `10.1287/trsc.1050.0135`。历史压缩归档保持原始哈希不变，正式说明与报告统一采用正确 DOI；Vidal 的预印本年份（2020）与期刊正式发表年份（2022）分别标注以便检索。
