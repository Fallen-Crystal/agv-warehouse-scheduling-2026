# 参考文献与实现对应（2026-10-24核对）

这些材料支持问题框架或算法思想；没有一篇替本项目证明50/30/20权重、六车动态最优性或实验收益。只链接论文与作者资料，不再分发版权PDF。历史报告的原引用保留作记录，以本文校正为准。

蚁群/粒子群的历史实验实现、超参数和当时引用见Selected_20261022_source_and_evidence.tar.gz中两套docs。它们用来探索离散订单序列、车归属或路径优先级，不把连续PSO坐标直接当可通行路径；最后仍需A*/SIPP作合法解码。本次没有把未获胜组合并入默认GA。

**引用勘误**：Coupled历史实验设计把Ropke–Pisinger的DOI误写为`10.1287/trsc.1100.0135`；正确为`10.1287/trsc.1050.0135`。本次保留原实验包不改哈希，当前说明和正式报告引用均应使用正确DOI。Vidal预印本2020/2021版本与2022期刊发表年分别注明，不混写为不同论文。

最初聊天图片中的异构AGV标题及学长报告属于思路背景；本次未取得足够原文证据来把图片中的所有性能/规模描述当成已核实结论，因此不补造引用或列作算法性能依据。学长可借鉴的是明确主线、独立适应度和对照实验，不是直接套用网约车地理距离及其收益。
