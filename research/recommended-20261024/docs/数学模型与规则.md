# 当前数学框架与业务规则（2026-10-24）

本文描述当前推荐程序实际采用的模型。旧包中的相对基准评分、有限待命、出库单一业务或其他候选设定只属于历史版本。本框架是离散约束优化描述，不声称已经实现一个可求解全部规模的统一MILP。

## 1. 问题与参数

仓库为图 $G=(V,E)$。$V$为可占用地面，$E$仅连接上下左右相邻格；等待也允许。墙、柱、设备、货架实体不可进入。车队 $K=\{1,\ldots,m\}$ 同构，每车容量1，一次只执行一项运输任务。每步1秒，每步最多走1格；不包含连续转弯、加减速、充电和真实电池模型。

模型可生成中/大/特大/超大四档：46×41、62×47、78×65、96×69格（当前默认作业通道参数）；本轮主实验固定大型62×47、6辆车、双排5层、900秒请求观察窗口。一般货架层数可选3–8，但首排单排始终只有1层。1格暂按离散距离单位，不自行声称等于1米。当前生成器预设8个停车位，主实验使用前6个。其他车数/层数/地图的历史测试不能代替本轮全组合验证。

任务集合 $J=J^{in}\cup J^{out}$。任务 $j$ 有类型、SKU、发布时间 $r_j$、固定映射的作业口和WMS分配的货位 $b_j,\ell_j$，以及合法装卸点集合 $P_j$。入库为入库口→货架；出库为货架→出库口。每次取放在相邻作业地面完成，不进入货架。

服务时间：货架第 $\ell$ 层连续作业 $s_\ell=2\ell$ 秒（第1–8层分别2/4/6/8/10/12/14/16秒）；口岸取/卸1秒。它们是统一实验假设，未由原厂测量标定。5层主场景为2/4/6/8/10秒；单排仅第1层2秒。

## 2. 决策与事件

$x_{kj}\in\{0,1\}$：任务归属；$\pi$：尚未分配任务的优先顺序；$p_k(t)\in V$：逐步位置；$a_j,u_j,f_j,C_j$：指派、取货到达、取货完成、卸/入库完成时刻。每个任务选择 $P_j$ 中一个合法作业点。SKU货位由确定性WMS规则分配，不由GA自由优化库位。

在决策时刻 $t$ 仅可访问 $J_t=\{j:r_j\le t\}$，不得读取未来请求或隐藏最终订单数量。已执行前缀和已派任务不重新归属，GA只搜索当前可见未派任务的车辆与顺序。900秒结束事件由外部发布器告知；算法收到事件前不知道将来是否还有单。

## 3. 可行性约束

1. **唯一服务及先后**：$\sum_k x_{kj}=1$；$a_j\ge r_j$；同车运输任务不重叠；先连续完成取货，再载货运输，后连续完成卸货。任务未全部完成或验解失败时不给有效低分。
2. **运动**：$p_k(t+1)=p_k(t)$ 或 $(p_k(t),p_k(t+1))\in E$；位置必须为整数合法网格。
3. **防碰撞**：对 $k\ne h$，$p_k(t)\ne p_h(t)$；禁止 $p_k(t)=p_h(t+1)$ 且 $p_k(t+1)=p_h(t)$ 的对向换位。预约表覆盖移动、等待和连续装卸。
4. **端口与作业面**：口岸只可用于对应取放服务，不可当穿越捷径或空闲停车点。背靠背两排独立编号、独立货物和作业面，不能跨排取货；单排只1层，可选择两侧合法相邻点。不允许隔格装卸。
5. **库存**：每货位 $q_b(t)\in\{0,1\}$；SKU库存遵守 $I_s(t)=I_s(0)+N_s^{in}(t)-N_s^{out}(t)\ge0$，这里计数为实际完成事件，而非发布事件。出库取货完成时扣库存，入库上架完成时增加；预留不等于实物已经移动，不可重复占用同一货位。
6. **层序及货架锁**：同一面同一格出库须先上后下，不能在上层有货时取下层；入库先填下层再填上层。同格不同层不可同时作业。当前实现还保守地从指派起预留该格，到出库取货完成或入库上架完成才释放，并避免同格相反类型预留重叠；该约束比仅锁装卸时段严格，不可在算法比较中偷偷放宽。
7. **待命/终止**：一批与下一批之间不强制返库；空车选择安全普通通行格待命，不能占端口、货架装卸邻格、他车固定停车位或阻断既有预约。真实流关闭且所有任务完成后才最终返各自H。若当前位置不适合待命，车辆可沿安全路径移到适合位置，并非每次卸货原地不动。路径包含可被新任务打断的后备返H预约，不等于每单实际强制返H。

## 4. 主目标及统计口径

完整执行从窗口起点0开始计时：

$$T=\max_{j\in J} C_j,\quad R=\frac{1}{|J|}\sum_{j\in J}(C_j-r_j),$$
$$D=\sum_{k\in K}\sum_{t=0}^{B-1}\mathbf1[p_k(t+1)\ne p_k(t)].$$

$B$为流关闭、全部任务完成并全车最终返H的真实最早结束时刻，不能追加停车尾部人为拉长。$T$不含最终返库时间；$D$含取货空驶、载货、待命换位和最终返库。$R$包含排队、等车、交通等待和连续作业。零任务按零需求处理；当前主实验均非空。

$$\min F=0.5\frac{T}{H}+0.3\frac{R}{H}+0.2\frac{D}{mvH},\qquad H=900\text{s},m=6,v=1\text{格/s}.$$

即 $F=0.5T/900+0.3R/900+0.2D/5400$。也可报告等价秒成本 $J=HF=0.5T+0.3R+0.2D/(mv)$。权重与尺度固定，不含另一算法的成绩作分母。F可大于1，0.8不是统一达标线；不同任务/地图/车数的绝对F不能随意比较。本轮权重是透明的课程业务偏好，文献并不证明50/30/20是唯一科学权重。

T体现整体清空速度，R体现订单响应，D体现总运动成本；R和D相关但不相同，路短也可能排队久。空驶距离、载货距离、空驶率、P90、交通等待、分类型耗时、工作量均衡、B、CPU均作辅助报告，不重复塞进F。固定任务和货位时部分载货成本可能近似不可压缩；不承诺所有指标同时达到各自最小值。未新增无真实字段支持的紧急等级，也不将0.05D称真实耗电。

## 5. 算法与模型的边界

数学目标是完整任务与路径上的F；在线算法只能优化当前已知任务的预测，不知道未来订单，故局部预测改善不能推出动态全局改善。当前候选预演将已知任务视为封闭集合并计其后备最终返程；真实执行仍按批次安全待命。开放流预测终点曾单独测试但退化，未并入默认策略。

联合GA是启发式；SIPP在固定其他车预约下搜索合法路径，优先规划多车并非联合全局最优。当前六车主场景没有已证明最优值或可保证近似比。CP-SAT微型参照缩减为两车少量静态任务，只对求解器返回OPTIMAL且通过独立验解的实例声称最优；FEASIBLE不等于最优。
