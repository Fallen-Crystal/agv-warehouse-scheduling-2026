# 匈牙利替换探索性实验

## 设计与解释边界

- 原精准匹配是精确最大匹配数、最小成本位掩码DP，不是贪心。相同矩阵下匈牙利不可能降低数学最优成本，但并列解、提交顺序会改变后续物理调度。
- 同成本变体仅替换求解器；F代理变体同时改变当前批次代价，不能将其收益全部归因于匈牙利求解器。
- 两变体各执行day41、52、59、65的一小时窗口一次：共504条不同订单，8次仿真；复用原最终DQN，无继续训练、无阈值门控。
- 正式F=0.5T/900+0.3R/900+0.2D/5400（越小越好），物理执行和GA预算不变。
- 原DQN的matching动作含义在替换后发生变化，未针对新动作重新学习；该结果是冻结策略干预效果，不代表新组合重新训练后的上限。
- 这些日期已在上一轮评估使用，本轮属于探索性诊断，不是新的独立泛化或显著性证据。

## 平均配对结果

- 同成本匈牙利：对原DQN平均改善0.068%；对固定GA平均改善0.060%。
  相对原DQN：改善1个日期、持平2个、退化1个。
  存在退化日期，即使平均改善也不能称为稳定优于原策略。
- F代理成本匈牙利：对原DQN平均改善0.041%；对固定GA平均改善0.032%。
  相对原DQN：改善2个日期、持平0个、退化2个。
  存在退化日期，即使平均改善也不能称为稳定优于原策略。

本轮不证明持续学习收益：两变体均未重新训练；也不根据已看过的4个日期直接认定可部署或具有普遍优势。

## 自学习能否一直变好？

不能保证。继续训练可能改善，也可能过拟合、灾难性遗忘或退化。本轮仅检验分支替换，未执行新的学习。
后续若训练，应先固定新动作定义，在训练/验证集上选择模型，并保留未用日期作最终测试；允许候选模型不如旧模型时拒绝部署，但这也不能保证未知未来数据单调改善。

8条结果均通过轨迹有效标志、正式F复算、奖励总账与分项、终局标记审计；冻结权重/优化器/经验池/RNG检查由运行器逐次执行；最终检查点哈希和执行源码哈希一致。
