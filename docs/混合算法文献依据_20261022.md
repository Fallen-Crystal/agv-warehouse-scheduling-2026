# 混合算法的文献依据与适用边界

本轮查阅的是原始论文或出版方页面，访问日期2026-10-22。文献提供算法结构依据，不能替代本仓库自己的性能测试，不能把论文中的改善百分比移植过来。

| 文献 | 可借鉴内容 | 与本实验的边界 |
|---|---|---|
| Xu等，IROS 2022，Multi-Goal Multi-Agent Pickup and Delivery | 任务序列邻域搜索与多车路径协调相结合 | 原文目标与完成性条件不等同于本项目的三项归一化F及特殊货架规则 |
| Li等，IJCAI 2021，MAPF-LNS | 从可行多车轨迹开始，选部分车辆重规划 | 原问题通常固定起终点，不直接解决动态订单分配 |
| Phillips与Likhachev，ICRA 2011，SIPP | 安全时间区间压缩时空搜索 | 单段、固定预约的性质不能推导多车调度全局最优 |
| Dorigo与Gambardella，IEEE TEC 1997，Ant Colony System | 信息素、启发信息与群体迭代 | 本轮仅借鉴ACO机制，不宣称实现了完整ACS |
| Kennedy与Eberhart，1995，Particle Swarm Optimization | 个体/群体最优引导的粒子更新 | 需要适配离散任务或通过A*解码空间参数，原PSO不直接保证网格避碰 |
| Information Sciences 2024，A hierarchical mission planning system for multi-uncrewed ground vehicles using fast cost evaluation and ant colony optimisation | 分层任务规划，以及A*与蚁群优化组合 | 原文涉及复杂地形与连续优化，本项目保持四邻接离散网格 |
| Wu等，PeerJ Computer Science 2024，A hybrid path planning algorithm combining A* and improved ant colony optimization with dynamic window approach for enhancing energy efficiency in warehouse environments | A*与ACO结合有直接仓库导航研究依据 | 原文包含DWA、转弯与物理能耗，不等同于多车订单F；本项目不引入连续轨迹与DWA |
| Swarm and Evolutionary Computation 2026，Multi-AGV collision-free scheduling framework with task allocation in high-density warehouses | GA任务分配、增强A*、多车冲突协调的分层耦合 | 原文规则、目标和交通约束不同；其摘要所述近优不构成本项目的近似比证明 |

当前实现优先保证可复现与规则兼容。它支持课程知识中的启发式A*、遗传搜索、蚁群、粒子群与组合优化，并通过有限预算真实预演连接两层算法。更复杂的群体算法并不必然优于SIPP或邻域搜索，结论只由本轮完整F、计算量、可行性和独立验证结果支持。
