# 仓库 AGV 在线调度与途中联合重规划

人工智能基础大作业任务 1：多取货任务并发下的仓库无人车调度。基于队友提供的 `agv_modeling_shelf` 教学仿真，加入 RHCR/MAPF-LNS 思想启发的在线联合后缀重规划，以及可选的当前可见订单最小代价匹配。代码仅使用 Python 标准库；图表生成是可选步骤。

**推荐首先阅读 [算法实现与实验报告](agv_modeling_shelf/算法实现与实验报告.md)，再看 [论文调研与算法选择](agv_modeling_shelf/论文调研与算法选择.md)。** 本项目实现途中多车联合改路，但不保证全局最优或任意可行实例必能求解；论文算法思想与本项目适配有明确区分。

## 快速运行

Python 3.10+，在仓库根目录执行：

```bash
cd agv_modeling_shelf
python3 show_warehouse.py
```

程序会打开本机页面。选择“仅联合重规划”是主要推荐配置；“匹配 + 联合重规划”是可选融合配置。可以生成场景、播放或逐步查看、保存完整 JSON、运行多个种子并下载统计 CSV。服务仅绑定 `127.0.0.1`，Ctrl+C 结束。

离线查看可直接打开 `算法优化轨迹.html` 和 `途中联合重规划解释.html`。离线文件支持查看保存轨迹；生成新任务需要上述本地 Python 服务。

## 检查与复现

```bash
cd agv_modeling_shelf
NO_PROXY=127.0.0.1,localhost no_proxy=127.0.0.1,localhost python3 -m unittest discover -v
python3 benchmark_algorithms.py --seeds 10 --output my_reproduction
python3 explain_replan.py
python3 verify_delivery.py
```

输出目录必须不存在，避免覆盖成绩。固定的正式实验保存在 `algorithm_results/`：6 类场景 × 10 个种子 × 4 种算法 = 240 次运行，每个算法使用完全相同的场景 JSON 和 SHA256。`summary.json`/`summary.csv` 是配对统计，`runs.csv` 是全部逐次成绩；失败不混入完整任务耗时比较。`algorithm_results_probe/` 是最初探索记录，正式报告只引用 `algorithm_results/`。

可选生成图表：

```bash
uv run --with 'matplotlib>=3.8,<4' python plot_results.py
```

也可以在自己的虚拟环境安装 `requirements-figures.txt` 后运行 `python plot_results.py`。模拟、测试、浏览器服务和已有图表查看不需要 matplotlib。

## 实测结果

每种场景 10 个相同种子，以下为全部成功的成对运行平均订单响应时间（出现到卸货完成，单位：步）。

| 场景 | 队友原版 | 仅联合重规划 | 降低比例 | 匹配 + 重规划 | 降低比例 |
|---|---:|---:|---:|---:|---:|
| 小型静态宽通道，4车12单 | 29.525 | 29.308 | 0.73% | 29.542 | -0.06% |
| 小型静态窄通道，4车12单 | 31.017 | 30.675 | 1.10% | 30.867 | 0.48% |
| 中型动态突发，6车30单 | 30.427 | 29.390 | 3.41% | 29.027 | 4.60% |
| 大型动态集中交付，8车40单 | 63.665 | 61.742 | 3.02% | 61.822 | 2.89% |
| 小型动态热点切换，4车30单 | 22.270 | 22.213 | 0.25% | 21.977 | 1.32% |

前 5 类场景每种算法均成功 10/10；100 步短时限压力场景每种算法均成功 0/10，完成单数和失败记录完整保留。收益并非所有种子都成立，且重规划增加运行耗时；具体成败次数、距离变化和耗时见报告。

## 文件结构

- `agv_modeling_shelf/`：完整队友项目内容，以及新增算法、测试、论文调研、说明报告、正式实验与可解释回放。
- `optimized.py`：算法驱动；保持原贪心或启用精确可见批次匹配。
- `joint_planning.py`：全车队/车辆对邻域，多优先级时空 A* 修复与严格改善接受。
- `environment.py`：保留原执行接口，新增可见已接任务信息和原子 `apply_replan()`。
- `benchmark_algorithms.py`：配对实验与消融；`test_optimized.py`：服务冻结、原子拒绝、在线隔离等回归测试。
- `artifacts/`：原版运行与测试记录、原始文件 SHA256、课程要求文字摘录、最终验证证据。课程 PPT 原文件不在仓库公开分发。

原文件夹里的历史建模说明和验证记录予以保留，属于队友版本记录；本次新增算法和当前成绩以本 README 及《算法实现与实验报告》为准。原始输入文件夹 `/Users/fallen/Desktop/agv_modeling_shelf/` 未修改。
