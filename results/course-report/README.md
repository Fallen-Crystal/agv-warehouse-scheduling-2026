# 大作业报告实验资料

对应报告《基于货位—车辆联合优化与反事实世界模型的仓库穿梭无人车智能调度》。报告使用 WEPA 真实订单流驱动课程仓库仿真，正式比较包含匈牙利指派、精确批次匹配、自适应 GA、DQN 选择、固定货位整数指派、货位—车辆联合优化、截单后反事实推演。各研究方案的公开实验入口与数据版本见[仓库首页](../../README.md)。

逐次表按 `(实验组, 案例, 方案, 种子)` 有 294 个唯一组合，由主要真实窗口 105 次、补充真实窗口 63 次、同步合成批次 126 次组成，订单数按运行求和为 18,354。逐行按 `F = 0.5*T/900 + 0.3*R/900 + 0.2*D/5400` 校核，最大绝对误差低于 `5e-16`。`T` 是最后一单完成时刻，`R` 是平均发布到完成时长，`D` 是含返库的总移动格数。

| 配对改善率 | 主要真实窗口 | 补充真实窗口 | 同步合成批次 |
|---|---:|---:|---:|
| 货位—车辆联合优化相对自适应 GA | 20.820241% | 5.003091% | 41.322019% |
| 完整方法相对自适应 GA | 20.842146% | 5.003091% | 43.227956% |
| 完整方法相对货位—车辆联合优化 | 0.033194% | 0.000000% | 3.529279% |

改善率按同输入、同种子计算 `100 * (1 - F_候选 / F_基线)` 后取平均。主要窗口完整方法的 `R` 和 `D` 分别下降 53.785365% 和 38.491532%。主要窗口共享 5 个订单输入，每个输入重复 3 个种子。将每窗三个种子均值视为一组，完整方法对 GA 为 5 个窗口全部改善，双侧精确符号检验 `p = 0.0625`。报告表 B7 的 `p = 6.10e-5` 对应 15 个非零配对均同号，计算将每个种子配对作为独立符号单位。

逐种子 S1–S3 明细、各敏感性设置的完整轨迹和验解输出目前缺少原始文件。报告的 360 次由表 20 的 `144 + 60 + 75 + 60 + 21` 得出。S6 用正式表的 T、R、D 独立复算了 231 组权重。完整方法相对 GA 的平均改善率范围分别为主要窗口 14.75%–53.79%、补充窗口 0.30%–36.81%、同步批次 25.84%–48.63%。完整方法在每个配对中均排名第一或并列第一的权重数依次为 149、231、174，与第 9.4 节一致。

公开仓库另有 [WEPA 开发窗口敏感性](../wepa-dev-sensitivity-20261120/REPORT.md)、[WEPA 验证窗口敏感性](../wepa-val-sensitivity-20261121/REPORT.md)及[通用引擎敏感性](../core-sensitivity-20261121/REPORT.md)，分别对应 200、156、205 次、各自的方案和输入协议。

## 输入来源与未归档证据

- WEPA 原始 411,830 条订单及库存、原布局和源文件哈希均在[原始数据说明](../../research/recommended-20261024/data/README.md)对应的目录。原始订单是输入记录。公开正式结果包含每次运行的订单数、平均响应和 P90。
- 报告所用五个主要真实窗口在[DQN 实验文档](../../research/dqn-experiment-v2/docs/匈牙利自适应GA-DQN重训练结果.md)有对应的早期单种子评估。五窗口、四种方案的 20 个 F 值均与正式逐次表的种子 0 完全相同。该研究阶段的冻结权重 SHA-256 为 `b09b93be34851e24ee199ac4b147573e381985d3923d641e4f38919528788bfa`，审计见[DQN 研究包](../../research/dqn-experiment-v2/README.md)。
- 从原始订单按 3600 秒对齐，并按报告表 3 的日编号、订单总数、入库数、出库数及 SKU 数筛选，三补充窗口在各指定日期均唯一命中。半开区间分别是 day54 `[4719600, 4723200)`、day59 `[5148000, 5151600)`、day83 `[7221600, 7225200)`。用这些重建输入运行历史冻结引擎的匈牙利基线，种子 0 的 F、T、R、D、交通等待、P90、返库时间和空驶距离都与正式逐次表一致，三次运行均通过当前的独立物理验解。
- 同步批次可按报告设置重建。订单 `i` 从 0 编号，偶数出库、奇数入库，源端口号为 `1 + i % 3`。SKU 为 101，初始库存 36，所有订单第 0 秒发布，第 1 秒截单。以此规则运行冻结引擎的匈牙利基线，6、12、18、24、30、36 单的种子 0 对应指标与正式逐次表一致。48、60、72 单的 F 与表 B6 显示值一致。这九次代表性复验都通过独立物理验解。
- 完整 294 次正式运行的逐订单完成时刻、入库与出库响应分解、逐秒车辆轨迹、调度日志和独立验解原件目前缺少对应的原始文件。报告中的 P99、积压曲线、逐秒碰撞与库存复核需要这些记录；逐次汇总表支持对评分和配对改善率的复算。
- 反事实规划记录支持核对各运行的计数。报告中候选完整成本、缓存命中与参考成本单调不增的逐决策复盘，需要每条分支的日志或完整轨迹。
- [课程报告运行入口](../../research/course-report/README.md) 按报告和附录恢复 CP-SAT 联合指派及截单后推演。当前入口生成的轨迹可独立验解。原始实验代码的准确提交、逐次运行命令和当时的完整输出清单仍待归档。[2026-10 WEPA 推荐版](../../research/recommended-20261024/current/README.md) 提供其协议下的 `gate` 及验解脚本。
