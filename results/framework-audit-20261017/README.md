# 框架审查证据

本目录记录正确性与接口审查，不是算法性能排名。方案、规则清单、接入说明和限制见[审查报告](../../docs/framework-audit-20261017.md)。

- `matrix.json`：96组几何/可达性参数组合、24次新边界执行、156条历史代表轨迹复查与1284行评分算术核对。只有`completed=true`才代表全部矩阵完成。
- `archive-downloads.json`：三份公开实验归档的字节数和Git blob校验值，来源固定于`ff0d8b7`。
- `verification.json`：本轮回归、输入变异和网页检查证据；最终CI以PR Checks为准。

复查历史轨迹前仅去掉目标分数相关字段，使用强化后的轨迹验解；保留事件、位置、逐车/逐单统计和状态标签。没有重算每条评分参照，也没有重跑全部历史执行。保留轨迹156条和CSV1284行是不同层次的证据，不能合称1284条完整轨迹重验。

新执行矩阵包含四种地图、1/10车、最高8层、共享交付点以及动态批次；每场景只测指定固定种子及两种显式策略。它证明所测组合可运行，不证明任意拥堵下算法完备或最优。

复现：安装项目后执行 `python scripts/audit_framework.py --archives <已解压的三份归档父目录> --output runs/new-framework-audit.json --workers 3`。必须使用不存在的输出文件；不提供archives参数则省略历史归档复查。
